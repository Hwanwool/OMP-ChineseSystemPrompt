# omp 中文系统提示词模板使用说明

 将 omp 默认的英文系统提示词翻译为中文，通过官方配置文件机制 SYSTEM_TEMPLATE.md 覆盖 block 0（默认指令块），保留 <project-context> 等自动生成内容。

 文件

 ┌──────────┬────────────────────────────────────────────────────────────────────────────────────────────────────┐
 │ 项       │ 值                                                                                                 │
 ├──────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 文件名   │ SYSTEM_TEMPLATE.md                                                                                 │
 ├──────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 类型     │ Handlebars 模板（纯文本，无依赖）                                                                  │
 ├──────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 覆盖方式 │ 替换默认英文指令块，保留 skills/rules/工具清单/项目上下文等自动生成部分                            │
 ├──────────┼────────────────────────────────────────────────────────────────────────────────────────────────────┤
 │ 翻译源   │ GitHub can1357/oh-my-pi packages/coding-agent/src/prompts/system/system-prompt.md（v18.10.1/main） │
 └──────────┴────────────────────────────────────────────────────────────────────────────────────────────────────┘

 │ 翻译原则：所有 Handlebars 标签（{{...}}）、变量名、helper、工具名、协议名原样保留，只翻译标签外的 prose；RFC 2119
 │ 关键词（MUST/SHOULD/NEVER/AVOID/MAY…）保留英文大写以稳定语义强度。

 安装

### 本机 / 全局覆盖

 把 SYSTEM_TEMPLATE.md 放到用户级 agent 目录：

 ┌───────────────┬─────────────────────────────────────────────────┐
 │ 平台          │ 路径                                            │
 ├───────────────┼─────────────────────────────────────────────────┤
 │ Windows       │ C:\Users\<用户名>\.omp\agent\SYSTEM_TEMPLATE.md │
 ├───────────────┼─────────────────────────────────────────────────┤
 │ macOS / Linux │ ~/.omp/agent/SYSTEM_TEMPLATE.md                 │
 └───────────────┴─────────────────────────────────────────────────┘

 ```sh
# macOS / Linux
mkdir -p ~/.omp/agent
cp SYSTEM_TEMPLATE.md ~/.omp/agent/
 ```

### 只对某个项目生效

 ```sh
mkdir -p <项目根>/.omp
cp SYSTEM_TEMPLATE.md <项目根>/.omp/
 ```

### 使用 profile 时

 ```sh
cp SYSTEM_TEMPLATE.md ~/.omp/profiles/<profile名>/agent/
 ```

 生效

 模板在会话启动时只读一次。安装后必须新开会话或重启 omp，改动才会生效。

 验证

 ```sh
omp -p --no-session "请原样复述你系统提示词的第一行文字，只输出那一行"
 ```

 预期输出（中文首行）：

 ```
RFC 2119 关键词：MUST、REQUIRED、SHOULD、RECOMMENDED、MAY、OPTIONAL。`NEVER` = `MUST NOT`；`AVOID` = `SHOULD NOT`。
 ```

 输出为中文即覆盖成功；若仍是英文，检查路径与优先级。

 部署到其他电脑

 1. 复制 SYSTEM_TEMPLATE.md 到目标机对应目录（见上表）。
 2. 确认目标机 omp --version ≥ 18.10.1；过旧建议先 omp update。
 3. 重启 omp。

# 示例：从源机 scp 到目标机

mkdir -p ~/.omp/agent
scp 源机:/path/to/SYSTEM_TEMPLATE.md ~/.omp/agent/

 ```

 定制修改

 直接编辑 SYSTEM_TEMPLATE.md 的 prose（中文/英文皆可），但必须保留全部 {{...}} 标签和结构。

 关键约束：

 - 标签是模板语法，改动后若不平衡/拼错会渲染失败。
 - 不要复制 /dump 导出的已渲染提示词来当模板（会冻结当时的设置/工具清单/设备数据）。
 - 升级 omp 后，用官方源 diff 一次，同步新增字段（{{toolInventory}}、{{xdevDocs}} 等）。

 卸载 / 回退

 删除或重命名模板文件即恢复默认英文提示词：

 ```sh
rm ~/.omp/agent/SYSTEM_TEMPLATE.md   # 删除，恢复默认
mv ~/.omp/agent/SYSTEM_TEMPLATE.md ~/.omp/agent/SYSTEM_TEMPLATE.md.bak  # 或备份后停用
 ```

 删除后重启 omp 生效。

 注意事项

 1. 优先级：同一作用域内 SYSTEM.md（纯文本）优先于 SYSTEM_TEMPLATE.md。若目标机已存在 SYSTEM.md，需先删除/重命名它，中文模板才会生效。
 2. 纯文本路线差异：改用 SYSTEM.md 会丢失默认模板的角色/工具策略/工作流等全部结构，只保留自定义文本 + 自动生成的 skills/rules。要完整中文提示词，务必用 SYSTEM_TEMPLATE.md。
 3. 版本降级安全：模板含 find/ast_grep/ast_edit/think 等新工具条件块；目标机未启用这些工具时对应段落自动不渲染，不会报错。
 4. 不经过扩展系统：本文件是配置文件，不是插件，--no-extensions 下依然生效。
