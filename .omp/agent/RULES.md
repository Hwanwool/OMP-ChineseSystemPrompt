# 语言与交流规则

- 始终使用简体中文回复用户，除非用户明确要求其他语言。
- 思考、推理与规划过程也使用中文。
- 代码、命令、标识符、文件路径、API 名称与专有名词保持英文原文。

# 术语约定

- 用户口中的 "omp" 指 oh-my-pi（本终端 AI Coding Agent，can1357/oh-my-pi），不是 oh-my-posh（prompt 引擎）。
- oh-my-pi 的 TUI 界面用 `symbolPreset: nerd`（`~/.omp/agent/config.yml`），图标/边框依赖 Nerd Font 字体；显示乱码通常是终端未切换 Nerd Font，而非 oh-my-pi 本身问题。
